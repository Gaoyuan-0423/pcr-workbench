# 界面语言 / Interface language

顶部 `中文 / EN` 控制 PCR 整个界面的语言。有效 `?lang=zh` / `?lang=en` 优先，随后读取 `localStorage['wisplab.lang']`，默认中文。切换使用 `history.replaceState` 保留其他参数和 hash；跨站导航携带 `lang`，因为不同域名的 localStorage 不共享。浏览器禁用存储时仍可切换本页语言。

`src/i18n/messages.ts` 保存中文源消息到英文的字典。组件通过 `useI18n().t()` 显式呈现文字。`translate.ts` 识别已有引擎报告的消息模板；只翻译指定的应用消息字段，不扫描或替换 DOM，不改变分析引擎、内部标识或保存的数据。新动态消息须同时补充字典及占位符测试。

语言切换不重置映射、对照组、内参、QC、分析结果或图表设置。文件名、原始表头、样本/基因/组名和自定义图题保持原文。CSV/Excel 的应用表头和说明随当前语言导出；数值与用户字段不变。Prism XML 的科学数据结构不变。AI 请求仅在用户主动点击时执行，并按当时语言生成解读；已有模型回答属于外部生成内容，切换界面语言不会自动重发或翻译它。

验收：`src/i18n/i18n.test.ts` 检查语言规则、模板占位符、用户字段与导出数据；`tests/e2e/language.spec.ts` 检查记忆/URL、英文各步骤与动态告警、移动布局、语言切换保留结果和图表设置、多板、多表、RDML、熔解摘要及禁用存储。原 `smoke.spec.ts` 保留中文全流程回归。
